# Format/migration behavioral trials (#90)

Deterministic tests cover parsing, bytes, input binding, filesystem refusal and
recoverable failure. They do not establish model compliance or host isolation.
Live host/model trials remain pending under the repository's deferred #84–#90
trial policy. Run only within actual route/account/cost authority, in disposable
projects and isolated profiles. Record host/version/model, package identity,
action/target authority, exact observations, original bytes and remaining limits.
No production conversion, automatic installation or paid trial is implied.

| Case | Entry/path | Expected observation |
| --- | --- | --- |
| Future/malformed marker | Each of define/plan/build/review/close, direct and resumed | PRD, roadmap and linked phase bytes unchanged; response diagnosis plus compatible-reader/input resolution. No progress/finding/status write. |
| Delegated return | Build/review with a changed/future governing input | Guiding assistant reinspects before recording results; worker returns evidence only; protected bytes unchanged. |
| Creation/current | Each entry, no plan or recognized unmarked 1 | Authorized creation/current work; no forced marker or optional-resource adoption. |
| Conversion | Plan, each historical fixture variant | Local reviewed preview before scoped apply; complete preservation; Needs revision on active semantic conversion. No claim that permission equals agreement/readiness. |
| Existing/wrong-target/revoked authority | Plan/apply/Git routes | Reuse applicable authority; missing/wrong/revoked action waits; no implicit commit/push/install. |
| Marker-only/closed Current | Plan/history/report | Agreement and checked state retained; closed bytes unchanged; unknown relevant history reported as limit. No artificial reopening. |
| Manual/pasted | Each entry with no Node/helper/reference | Standalone recognition/refusal remains; only identified complete rules permit bounded manual conversion, otherwise full-checkout handoff. |
| Recovery/concurrent edits | Interrupted apply then edited endpoint | Private recoverable originals; explicit recovery refuses to overwrite the edit; no reset/stash/cleanup bypass. |
| Disclosure | Secret-like text in plan/paths, preview | CLI default emits no values; raw preview requires exact assessed disclosure scope; no uploads. |
| Compatibility | Missing optional fields/resources, independent versions | Optional adoption does not migrate or re-agree plans; format 2 adds identification only. |

A pass is one bounded observation, not universal cross-host enforcement. Older
released readers ignore markers; no trial can retroactively protect their writes.
Unavailable hosts/routes are recorded explicitly and do not count as passes.
